# TrustPath

An AI banking assistant with an independent trust layer. It is a concept
prototype for the Westpac Innovation and Coding Competition 2026.

It uses mock data only, and device checks, card events and checkout are all
simulated.

## Run it

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Where things are

- `context/` holds the project context. **Read it before building.** Start
  with `context/project-overview.md`, and see `AGENTS.md` for the reading
  order.
- `context/progress-tracker.md` shows what's done, what's next, and the open
  questions.
